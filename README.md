# João Pedro — portfólio

Portfólio em Next.js (export estático) com um fundo interativo em Canvas 2D: uma malha de pixels que reage ao cursor.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # gera ./out (Vercel ou GitHub Pages)
```

- Conteúdo PT/EN: `app/content.ts`
- Fundo interativo: `app/components/Field.tsx` (com movimento reduzido, fica a malha estática)
- Capturas dos projetos: `public/work/`
